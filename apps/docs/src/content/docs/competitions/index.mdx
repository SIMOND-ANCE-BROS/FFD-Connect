# Module Compétitions 🏆

FFD-Connect te permet de suivre l'actualité des compétitions de danse sportive en France et à l'international. Que tu sois danseur, spectateur ou organisateur, ce module regroupe toutes les informations essentielles.

## Ce que tu peux faire

| Action                                   | Profil concerné | Disponibilité      |
| ---------------------------------------- | --------------- | ------------------ |
| Parcourir le calendrier des compétitions | Tous            | 📱 Mobile · 💻 Web |
| Voir la liste des participants           | Membre, Staff   | 📱 Mobile · 💻 Web |
| Consulter les résultats finaux           | Tous            | 📱 Mobile · 💻 Web |
| Suivre les résultats en direct           | Tous            | 📱 Mobile          |

## Accéder aux compétitions

Sur l'application mobile, appuie sur l'onglet **Compétitions** (représenté par un trophée 🏆) dans la barre de navigation principale.
