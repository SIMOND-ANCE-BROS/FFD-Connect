# Consulter les résultats

Une fois la compétition terminée et les résultats validés par les juges, ils sont disponibles pour tous sur FFD-Connect.

## Étapes

<TourStep step={1} title="Recherche une compétition passée">
  Dans l'onglet **Compétitions**, tu peux changer de vue pour afficher les compétitions **Terminées**.

![Filtre compétitions terminées](/screenshots/placeholder.png)
</TourStep>

<TourStep step={2} title="Ouvre la section « Résultats »">
  Sélectionne la compétition, puis appuie sur **Résultats**.

![Onglet Résultats](/screenshots/placeholder.png)
</TourStep>

<TourStep step={3} title="Détail des scores">
  Appuie sur un couple pour voir le détail de ses notes par danse et par juge si ces informations sont publiées.

![Détail des scores par juge](/screenshots/placeholder.png)
</TourStep>
