title: Auth Module (Backend)
description: Overview of the authentication module.
---

Ce module gère l'authentification et l'autorisation des utilisateurs.

## Fonctionnalités

- Connexion via JWT.
- Gestion des rôles.
- Protection des routes API via `@ApiBearerAuth()`.

## API Reference

Les endpoints de ce module sont disponibles dans la [Référence API](/api/auth).
