La feature Player permet aux utilisateurs de gérer et de lire des musiques pour les compétitions.

## Fonctionnalités

- Lecture audio haute performance.
- Mise en cache locale des pistes.
- Intégration avec le module de scan.

## Architecture UI

- ViewModel: `usePlayerLogic.ts`
- View: `PlayerScreen.tsx`
