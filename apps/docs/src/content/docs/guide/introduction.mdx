# Bienvenue sur FFD-Connect 🎉

FFD-Connect est la plateforme officielle de la **Fédération Française de Danse** pour gérer tes licences, suivre les compétitions, et organiser les événements de ton club.

## À qui s'adresse l'application ?

<ProfileBadge profiles={["Membre", "Staff", "Responsable de club", "Admin"]} />

FFD-Connect est conçue pour plusieurs types d'utilisateurs :

| Profil                  | Ce que tu peux faire                                               |
| ----------------------- | ------------------------------------------------------------------ |
| **Membre / Danseur**    | Gérer ta licence, suivre les compétitions, écouter ta musique      |
| **Staff**               | Suivre les résultats et les participants d'un événement            |
| **Responsable de club** | Gérer les membres de ton club, créer et organiser des compétitions |
| **Admin**               | Accès complet à la plateforme                                      |

## Disponible sur mobile et web

- **📱 Application mobile** — iOS & Android, disponible sur les stores
- **💻 Version web** — Accessible depuis n'importe quel navigateur

Certaines fonctionnalités sont disponibles uniquement sur mobile (ex: scanner de fichiers audio). Chaque page de cette documentation précise la disponibilité.

## Comment utiliser cette documentation ?

Navigue dans la sidebar à gauche selon ce que tu veux faire :

- 📋 **Licence** — Tout ce qui concerne ta carte de membre et licence WDSF
- 🏆 **Compétitions** — Parcourir les événements et voir les résultats
- 🏠 **Club** — Gérer ton club et ses membres
- 🎵 **Bibliothèque musicale** — Gérer ta musique pour les compétitions
- ⚙️ **Mon compte** — Paramètres et sécurité
