# Ajouter une licence WDSF

Si tu participes à des compétitions **internationales**, tu dois posséder une licence **WDSF** (_World Dance Sport Federation_) en complément de ta licence FFD. Voici comment la lier à ton profil.

> **Pré-requis** : Tu dois déjà posséder un numéro de licence WDSF. Pour en obtenir une, contacte directement la [FFD](https://www.ffd.fr).

## En cas de problème

| Problème           | Solution                           |
| :----------------- | :--------------------------------- |
| Numéro non reconnu | Vérifie le numéro auprès de la FFD |
| Licence déjà liée  | Contacte le support FFD-Connect    |
| Erreur réseau      | Vérifie ta connexion et réessaie   |
