## Ce que tu vois sur cet écran

| Information           | Description                                       |
| --------------------- | ------------------------------------------------- |
| **Statut**            | Active ✅ / Expirée ❌ / En attente ⏳            |
| **Date d'expiration** | Date jusqu'à laquelle ta licence est valide       |
| **Numéro de licence** | Ton identifiant unique FFD                        |
| **Licence WDSF**      | Indique si tu possèdes une licence internationale |

## Licence expirée ?

Si ta licence est expirée, consulte la page [Renouveler ma licence](/licence/renouveler/) pour connaître la procédure.
