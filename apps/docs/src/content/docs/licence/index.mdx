# Module Licence 📋

La **licence FFD** est ton sésame pour participer aux compétitions officielles de la Fédération Française de Danse. L'application te permet de la gérer directement depuis ton téléphone ou le web.

## Ce que tu peux faire

| Action                            | Disponible sur     |
| --------------------------------- | ------------------ |
| Consulter le statut de ta licence | 📱 Mobile · 💻 Web |
| Ajouter une licence WDSF          | 📱 Mobile · 💻 Web |
| Renouveler ta licence             | 📱 Mobile · 💻 Web |

## C'est quoi une licence WDSF ?

La **WDSF** (_World Dance Sport Federation_) est la fédération internationale de danse sportive. Si tu participes à des compétitions internationales, tu dois disposer d'une licence WDSF en plus de ta licence FFD nationale.

## Accéder au module Licence

Rends-toi dans l'onglet **Profil** de l'application, puis appuie sur **Ma Licence**.
