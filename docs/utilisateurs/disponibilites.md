# Ce que vous pouvez tester dans la bêta

FFD Connect est une version de test indépendante. Un écran présent dans l’application ne garantit pas que toutes ses actions soient disponibles pour tous les comptes. Les repères ci-dessous distinguent la fonction, le rôle nécessaire et ses limites.

## Les fonctions présentes

| Fonction                            | Pour qui ?                                              | À savoir avant d’essayer                                                                                                                |
| ----------------------------------- | ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Compétitions                        | Tous les espaces ; les actions varient selon les droits | Les fiches, programmes et résultats dépendent des données disponibles. Une inscription peut nécessiter la validation du club.           |
| Licence numérique                   | Espace Danseur                                          | La carte de la bêta et son pass Wallet ne sont pas encore acceptés en compétition. Utilisez le justificatif demandé par l’organisation. |
| Bibliothèque musicale               | Danseur et Admin                                        | Les titres et actions accessibles dépendent de votre compte et du contenu disponible.                                                   |
| Espace club                         | Compte disposant du rôle Club                           | Le rattachement au club est nécessaire. Les inscriptions en attente apparaissent selon son mode d’inscription.                          |
| Scanner                             | Staff, Club et Admin                                    | L’accès à un événement dépend des autorisations. La caméra et une validation par le service sont nécessaires.                           |
| Administration des comptes et clubs | Administrateur habilité                                 | Ce parcours se fait dans le back-office web, distinct de l’espace Admin mobile.                                                         |

Pour changer d’espace lorsque vous disposez de plusieurs rôles, consultez [Espaces et compte](./espaces-et-compte.md). Le sélecteur ne crée pas de nouveaux droits.

## Les limites à connaître

- **Licence et Wallet** : ne remplacez pas votre justificatif habituel par la carte de la bêta. Sur iOS, le bouton Wallet est conditionnel et son absence n’indique pas nécessairement une panne.
- **Inscriptions** : ouvrir une fiche ou un formulaire ne confirme pas votre participation. Vérifiez le statut de la demande.
- **Contenus absents** : un programme, un résultat ou un morceau peut ne pas encore être disponible. Ce n’est pas forcément un problème de votre téléphone.
- **Version de test** : des bugs peuvent survenir. Dans l’app, utilisez **Réglages → Faire un retour** pour les signaler.

## Ce qui relève encore du projet

Les sujets et jalons du projet ne sont pas une liste de fonctions déjà livrées. Leur présence sur la landing ne signifie pas qu’ils sont accessibles dans votre version. Consultez les [jalons du dépôt](https://github.com/SIMOND-ANCE-BROS/FFD-Connect/milestones) pour suivre les évolutions ; aucune date de disponibilité n’est garantie par cette page.

## Le site n’est pas votre compte personnel

Les écrans interactifs du site sont des **adaptations web avec des données fictives**. Ils permettent d’explorer certains parcours, sans inscription réelle, QR utilisable, musique diffusée ni modification de votre compte. Les dialogues qui expliquent une action ne constituent pas une validation de cette action dans l’app.

Pour commencer dans l’application, suivez les [premiers pas](./premiers-pas.md), puis votre parcours : [danseur](./danseurs.md), [club](./clubs.md), [staff](./staff.md) ou [administrateur](./administrateurs.md).
